# DebateSpace

Fact-checking search engine with government sources, news articles, and YouTube videos.

## Features

- Fact checking with cited sources
- Government website search (.gov, .gc.ca, .gov.uk)
- Real news articles from GNews API
- YouTube video explanations
- Clean, modern interface

## Tech Stack

- Frontend: HTML, CSS, JavaScript
- Backend: Vercel Serverless Functions
- APIs: Tavily, GNews, YouTube, Google Custom Search

## Setup

1. Clone the repository
2. Add your API keys to Vercel environment variables
3. Deploy to Vercel

## Environment Variables

- `TAVILY_API_KEY`
- `GNEWS_API_KEY`
- `YOUTUBE_API_KEY`
- `GOOGLE_SEARCH_API_KEY`
- `GOOGLE_SEARCH_CX_NA`
